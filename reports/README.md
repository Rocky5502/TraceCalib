# Experiment Reports

Codex/local execution should create, in order:

1. `PRE_FLIGHT_REPORT.md`
2. `PILOT_REPORT.md`
3. `SCALE_UP_DECISION.md`
4. `RQ1_REPORT.md`
5. `RQ2_REPORT.md`
6. `RQ3_REPORT.md`
7. `RQ4_REPORT.md`
8. `NEGATIVE_RESULTS.md`
9. `FINAL_AUDIT.md`

Reports are narrative summaries of machine-readable artifacts, not substitutes for them.
