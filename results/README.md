# Generated Results

Do not manually type result numbers into this directory.

Expected generated structure:

```text
results/
├── metrics/
├── tables/
├── figures/
├── models/
├── predictions/
├── statistical_tests/
└── manuscript/
```

Every table must be emitted as long CSV, formatted CSV, JSON, and LaTeX. Every figure must have source-data CSV plus PDF/SVG/PNG outputs and provenance metadata.

`configs/results.yaml` is the machine-readable reporting contract.
